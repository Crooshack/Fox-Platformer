## 🎮 About the Game

FoxPlatformer is a 2D platformer where you play as a fox exploring two unique levels: Day ☀️ and Night 🌙.  
Collect stars ⭐, avoid eagles 🦅, and enjoy colorful pixel art with smooth controls.
